# Income model (what each source pays per run)

Generated by `FaucetModelTest` (`./gradlew :domain:test --tests '*FaucetModelTest'`, also written to `domain/build/faucet-model.md`). It draws 4000 seeded players per source from the real reward bands, so it follows the code instead of a copy of its numbers; `tools/analyze_balance.py` is the older prototype model and does not cover these sources. The figures are the shipped defaults (a configured server will differ), and they are expected values per run before the daily budget.

The daily budget lets a player collect 20 full chests a UTC day (then 25% of the dust), so the most dust a day can pay at full rate is 20 times a row's dust.

## Things the table shows

- A Tower completion with no cards already pays 560 dust and 4 facets; a tier-10 Dungeon run pays 372 dust and 3.8 facets. Facets are the closest the Dungeon comes to the Tower, and they gate promotions, so watch this one first in the telemetry (`ledger` events with `detail` `dungeon_run`).
- Unique Fragments: the Tower pays 6.8 to 11.5 a completion, a Dungeon 0.35. Only the Tower is a realistic Catalyst source.
- Cores come only from the Tower (0.04 at the mini chest, 0.29 to 0.93 at the completion), as designed; the model fails if a Dungeon or Trial ever pays one.
- The most a day can pay at full rate is 20 chests: 11,200 dust from bare completions, 36,000 from a 6-card flawless one.
- Sigils: 0.02 a mini chest, 0.14 to 0.40 a completion, 0.02 to 0.09 a Dungeon run.

The telemetry log (`docs/PERFORMANCE.md`) measures the real rates; compare them with this table after the first week.
